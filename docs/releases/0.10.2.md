# Skills Auditor 0.10.2

Repairs failures found while reviewing the maintained Skill, CLI, schemas, and
supporting tests together:

- Git inspection failures and missing remotes no longer report a clean sync.
- Metadata parsing ignores `name:` in body examples and preserves quoted YAML
  hashes and inline comments. Duplicate discovery follows top-level installed
  links while keeping their installation paths for routing.
- Routing a bundle with only other-platform variants keeps its existing primary
  fallback without emitting an illegal state transition.
- Sync aliases, ledger IDs, trace IDs and sensor log components cannot escape
  their declared roots. Same-second routing runs receive distinct trace IDs.
- Integration plans and receipts cannot overwrite reviewed sources, required
  files or installation targets. The verification schema accepts and constrains
  the existing `required_file` check and approval reason.
- Workspace includes reject external symlink ancestors before traversal, and
  worker requests reject non-object JSON with a protocol error.
- Incident tests retain the standard unittest assertion failure behavior.
  Previously a fixture helper named `fail` could swallow failed assertions.

Installation guidance preserves the user's disabled capture preference and
states the `tomli` dependency on Python below 3.11. Artifact test installation now
resolves that declared runtime dependency. Skill Trace's plugin version and hook
trust remain unchanged.

Validation uses temporary synthetic files, mocked failures, process-crash
fixtures, the complete unit suite, and smoke/E2E tests of a freshly built wheel.
Cloud and real-agent experiments remain dated historical evidence; they were not
rerun for this patch. Host activation is a separate operation.
